Format
------
Superhero and enemy are 32 x 32 pixels.
Backdrops are 128 x 96 pixels.
Tileset is 8 x 8 blocks.
All in png format and sharing one 16-colour palette.​
Aseprite format files for the above.


Notes
-----
Graphics have been supplied as single frames and sprite sheets. Some objects are duplicated in the tilesets incase they are just to be used as fixed scenery.

Objects with the suffix "_bg" are designed to be animated in background layers (e.g. a distant chopper or car traffic)

Don't replace existing tilemaps, add these as new ones as they are completely different to the previous ones.
It is assumed that any tileset work will be done using editors that support X/Y flips.
If this is a problem, please contact me.
